# AgriConnect F2C

**Direct Farmer-to-Consumer Marketplace**
*Smart India Hackathon 2026 | Problem Statement ID: 26033*

## Overview
AgriConnect F2C is a digital ecosystem that directly connects farmers and consumers, eliminating multiple intermediaries. This improves farmer earnings and reduces consumer prices.

## Core Features
- Direct Farmer-Consumer matching
- Role-based Dashboard (Farmer, Consumer, Admin)
- AI Price Recommendation & Demand Prediction
- Voice IVR support for accessibility

## Tech Stack
- Frontend: React, Vite, TypeScript, TailwindCSS
- Backend: FastAPI, Python, Pydantic
- Database: Supabase (PostgreSQL)
